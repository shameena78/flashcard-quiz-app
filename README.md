# 📇 Flashcard Quiz App

A simple and interactive flashcard quiz application built with Python and Streamlit.

## ✨ Features

- 📚 View flashcards with questions and answers
- 🔄 Navigate between flashcards
- 👀 Show/hide answers
- ➕ Add your own flashcards
- ✏️ Edit existing flashcards
- 🗑️ Delete flashcards
- 🎯 Simple and beginner-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit

pip install -r requirements.txt
